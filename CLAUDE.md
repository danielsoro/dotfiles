# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

nix-darwin + home-manager + nix-homebrew configuration for a single Apple Silicon Mac. The flake exposes one output, `darwinConfigurations."dcunha"` (hostname `godofredo`, user `dcunha`, `aarch64-darwin`). There is no NixOS, no Linux target, and no CI.

## Commands

Apply the configuration (also available as the `switch` zsh alias defined in `flake.nix`):

    sudo darwin-rebuild switch --flake ~/.config/nix#dcunha

Under zsh the alias is prefixed with `noglob` because zimfw enables `EXTENDED_GLOB`, which makes `#` a glob operator. Use the same prefix or quote the flake ref when running the command by hand.

Other commands used in this repo (none are wrapped in a Makefile or script):

    nix flake update          # bump flake.lock; committed as "chore: update flakes"
    nix flake check           # evaluate the darwin configuration
    nixpkgs-fmt flake.nix     # formatter used in this repo (it is in systemPackages)

There are no tests. Verification is `nix flake check` followed by a `switch`.

Commits follow Conventional Commits via commitizen (`.cz.toml`, `CHANGELOG.md` is generated by `cz bump`). Changes land through GitHub PRs.

## Layout

Everything is inline in `flake.nix`; there are no `modules/`, `hosts/` or overlays. The file has two inline modules defined in a `let` block:

- `configuration`: the nix-darwin system module. Holds `environment.systemPackages`, fonts, macOS defaults (dock, Finder, NSGlobalDomain), Touch ID for sudo, the Homebrew declaration (taps, brews, casks with `cleanup = "zap"`), and two activation scripts.
- `homeconfig`: the home-manager module for user `dcunha` (`useGlobalPkgs`, `useUserPackages`, `backupFileExtension = "backup"`). Holds git, zsh, fzf, scmpuff, mise and the ghostty config.

`dotfiles/` holds files linked into the home via `xdg.configFile` / `home.file` (currently `ghostty.config`). `dotfiles/zsh-custom/` is a leftover oh-my-zsh theme that is no longer referenced.

## Non-obvious decisions to preserve

- **Package placement.** CLI tools from nixpkgs go in `environment.systemPackages`; GUI apps and tools that need macOS-native builds go through `homebrew.casks` / `homebrew.brews`. Nix GUI apps are aliased into `/Applications/Nix Apps` by the `activationScripts.applications` script using `mkalias`, so Spotlight finds them.
- **zimfw owns the zsh plugin stack.** `programs.zsh.enableCompletion` and `enableSyntaxHighlighting` are deliberately `false` on the nix-darwin side because zimfw's `completion` and `zsh-syntax-highlighting` modules handle them. The module list lives in `home.file.".zimrc".text`. Its `onChange` hook removes `~/.zim/init.zsh` because Nix store symlinks carry a 1970 mtime and zimfw would otherwise never rebuild. `programs.zsh.initContent` bootstraps zimfw from `${pkgs.zimfw}` on first run.
- **Shell environment side effects.** `initContent` exports `GITHUB_TOKEN` from `gh auth token` and sets `DOCKER_HOST` to the Docker Desktop socket. Keep these in mind when reasoning about tooling that reads those variables.
- **Rosetta** is installed by `activationScripts.extraActivation` and `nix-homebrew.enableRosetta = true`; both are required for the x86 casks.
- **Git signing** is on by default (GPG key in `programs.git.signing`); pinentry comes from the `pinentry-mac` brew.
